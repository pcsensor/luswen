# luswen

Justin 的个人博客，基于 Astro、Tailwind CSS、Content Collections 和 MDX。

## 快速开始

```bash
npm install
npm run dev
```

## 常用命令

```bash
npm run check        # 架构边界 + Astro 类型检查
npm run build        # 完整检查并生成静态站点
npm run preview      # 预览生产构建
```

## 写文章

在 `src/content/posts/` 中新增 `.md` 或 `.mdx` 文件。元数据字段、写作约定和发布流程见 [内容模型](docs/content-model.md)。
